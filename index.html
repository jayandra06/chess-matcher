Competition rules

Adjust table movement and scoring assumptions before using the tracker.

Scoring: win = 1 point, loss = 0 points, draw = 0.5 points each.
Winner stays at the same table.
Loser moves to the next higher table: 6 → 7 → 8 → 9 → 10. A loser at Table 10 moves to Table 6.
Pairings generated by this app avoid rematches where possible, but with an odd number of present players or absent players, a bye/absence policy may be needed.


Scores are stored in the database. Use Excel only to import a file or download a copy.
